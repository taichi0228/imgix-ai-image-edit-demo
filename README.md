# カインズ様向け AI Image Edit デモ

`ai-image-edit=packaging` + `ai-image-edit-analysis=true` の効果を、カインズ様の実画像で見せるためのモックアップ。

## デモの流れ

1. 上部バーは **通常配信** で開く。ふつうの EC サイトに見える状態。
2. **AI補正 ON** を押す → 全画像の URL 末尾に 2 パラメータが付く。ページ全体が差し替わる。
3. **Before / After** セクションのスライダーで 1 点ずつ効果を確認。

トグルで変わるのは URL のクエリだけ。原本も HTML の構造も一切変えていない。

## 話すポイント

- **`ai-image-edit=packaging`** — 袋・パウチのシワ、箱・缶・瓶のへこみ、強すぎる影と露出を補正。バーコード・成分表示・ロゴは保護されるので法令表示が崩れない。
- **`ai-image-edit-analysis=true`** — 本処理の前に軽量解析が走り、補正が必要な画像かを自動判定。不要なら原本のまま配信され、フルクレジットを消費しない（解析 0.5 クレジットのみ）。だから家具・家電・バナーを含む全点に同じ URL を当てられる。
- **原本は保持される** — パラメータを外せばいつでも元に戻る。撮り直し・レタッチ外注なしで既存カタログ全点の底上げができる。

## 注意

- Premium 機能。クレジットを消費する（出力サイズにより 2〜10 + 解析 0.5）。
- 初回リクエストは HTTP 423（レンダリング中）を返す。`index.html` は 423 を検知して自動リトライするので放置で埋まるが、**商談前に一度ページを開いて全部出し切っておくこと**（2 回目以降はキャッシュから即時）。
- 本番提案では URL 署名を推奨。
- **価格・レビュー件数は掲載していない**（実データを持っていないため、創作値を出さない方針）。
